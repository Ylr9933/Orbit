# Orbit · 让实验有迹可循

打开 `index.html` 即可演示，无需构建或启动服务。字体和动画已内嵌，截图从同目录的 images/ 读取，断网可用。
推荐使用 16:9 横屏或浏览器全屏演示。
采用 guizang-ppt-skill 的电子杂志模板与「牛皮纸」主题：卡其纸色、深棕墨色、衬线大标题。

## 操作

- `←` / `→`、空格、滚轮或左右滑动：翻页。第 7 页按步骤推进，再进入下一页。
- `Esc`：页面总览；点击缩略图跳页。
- `B`：静态模式，关闭背景和入场动画。
- `P`：演讲者模式，弹出独立观众窗口；需要允许浏览器弹窗。
- 演讲者模式提供讲稿、计时、排练、激光笔、圈选和观众屏恢复。该模式的 `B` 是黑屏。
- 可用 `index.html?slide=5` 直接打开第 5 页。浏览器打印可导出横向 PDF。

页面共 15 页。没有指定演讲时长，因此备注不预设分钟数，也不默认自动翻页。
本地修改的讲稿保存在当前浏览器，分享 HTML 不会带走这些修改。

## 内容与页面计划

资料截至 2026-10-09，来自当前仓库的 [README](../../README.zh-CN.md)、[设计](../design.md)、
[状态](../status.md)与已完成的飞书、插件任务记录。示意图表达结构，不展示伪造的实验结果。
单机、benchmark、多节点和飞书功能分别说明验证范围。

叙事顺序：为什么需要 → 如何分工与组织 → 实验如何运行 → 如何复盘 → 如何扩展 → 怎样开始。

| 页 | 页面 ID | 主题 | 版式 | 目的 |
| --- | --- | --- | --- | --- |
| 01 | cover | hero light | 封面 | 先建立产品定位，再说明整场介绍的主线。 |

| 04 | architecture | dark | 图文混排 | 让观众知道入口、服务、执行环境和记录分别在哪里。 |
| 05 | modules | light | 模块矩阵 | 解释实际模块分工，同时保留一个 Run、一套资源账本和记录路径。 |

| 07 | lifecycle | light | 流程图 | 按实际运行顺序讲清检查、等待、执行、记录和清理。 |

| 10 | review | dark | 图文混排 | 用提供的真实界面说明如何从一次 Run 找回证据。 |

每页的目的、补充讲述和转场均保存在 HTML 的 `SPEAKER_NOTES` 中。后续可直接编辑 HTML 的
`section[data-slide-id]`，重排页面时同步重排备注，保留稳定 ID。
