# R3: benchmarks on the Run / lease model

`refactor/ts-rewrite` · base `df2679a` (R2) · completed (pending user testing) · 2026-09-30T16:45:00+08:00

## Goal

Acceptance (design §10): the ASI native wrapper and the TB-Science Harbor format run on the same Run /
lease model; a method comparison page; a guide for integrating new benchmarks. Each new benchmark:
oracle full score, empty answer zero, sampled results consistent with the original.

## Changes

- `bench/` (new module; design §7):
  - `registry.ts`: benchmarks in `~/.orbit/benchmarks.json` (path, adapter, python, env, pass-env names).
  - `adapter.ts`: `Adapter` contract (`tasks / solveSpec / verifySpec / score`), Agent CLI commands.
  - `harbor.ts`: `task.toml` tasks (smol-toml); top-level `artifacts` collected from the solve run and
    mounted into a separate verifier Run; reward from `reward.txt` / `reward.json`; unsupported tasks
    (compose, shared verifier, bad toml) listed with reasons.
  - `asi.ts`: ASI-Bench seed31415 via its native runner as a process Run; oracle copies public
    references; verify Run scores a copy of the results (missing `.outputs` → empty, scored 0);
    scorer internal errors and unusable models are `invalid`.
  - `classify.ts`: execution / evaluation (valid, invalid, unknown) / cleanup kept apart.
  - `service.ts`: jobs and trials in sqlite, trial state machine driven by run events, verify runs at
    priority 1, cancel; `summarize` (valid-only means) and `compareJobs` (all-valid and paired means).
- `runs/process.ts` + `runs/shim.ts`: process backend (process group, private HOME, run dir outputs)
  and a `docker` shim that labels child containers `orbit.parent`, maps `--gpus` to the lease, adds
  host network to builds and injects agent auth; cleanup removes labelled containers.
- Contracts, store, daemon routes (`/api/bench/...`), client, CLI `orbit bench add|ls|rm|tasks|run|
  jobs|show|cancel|compare`; dependency `smol-toml`.
- Web: `/bench` (jobs, benchmarks, selection → compare), `/bench/<id>` (method cards, task × method
  heat matrix linked to runs, issues), `/bench/compare` (all / paired means with deltas); nav `g b`.
- Docs: design §7 rewritten, `docs/guides/bench-adapter.md`, README, SKILL.md, status.
