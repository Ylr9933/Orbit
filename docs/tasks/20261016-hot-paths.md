# Hot-path performance and resource use
branch: perf/opt4-hot-paths · status: completed · updated: 2026-10-16

## Goal
Reduce repeated trial parsing, task discovery and event listeners while preserving benchmark results and keeping snapshot writes outside source repositories.

## Changes
- Use an indexed SQL completion check and one aggregate query for listed jobs, retaining shared task-weighted metric statistics; skip ordinary run events before trial lookup.
- Cancel runs before advancing cancelled trials in the background; cache registry parsing and resolve flat Harbor tasks directly, preserving nested ID rules.
- Share HTTP wait/SSE listeners and release subscriptions, timers and abort callbacks.
- Isolate temporary Git objects/indexes and expose skipped submodules through the defaulted snapshot contract, warning events, CLI and Web.
