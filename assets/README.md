# Orbit brand assets

| File | Use |
| --- | --- |
| [orbit-logo.png](orbit-logo.png) | Logo with wordmark for READMEs and presentations on light backgrounds. |
| [orbit-icon.png](orbit-icon.png) | Standalone mark for Web navigation, the browser favicon and project avatars. |

These PNGs retain the supplied artwork and transparency. The Web UI places the dark icon on a
light surface so it remains visible in both themes. Vite bundles the referenced icon from this
directory into the Web assets shipped with the npm package.

Keep shared project branding here. Documentation-specific illustrations and badges belong in
`docs/assets/`; slide images remain with their presentation under `docs/ppt/`.
